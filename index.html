Jedes Pixel ist eine Zahl c. Gefragt wird, ob die Folge z → z² + c beschränkt bleibt. Bleibt sie es, gehört c zur Menge – das ist das Schwarze. Draußen zeigt die Helligkeit, wie schnell die Folge entkommen ist.
